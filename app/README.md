# FFJM Trainer — app

React + Vite + TypeScript front end. See [`../docs/technical-architecture.md`](../docs/technical-architecture.md) for the architecture decisions this follows, and [`../specifications/`](../specifications/) for the user stories it implements.

```bash
npm install
npm run dev      # dev server
npm run build     # type-check + production build to dist/
npm run lint      # oxlint
```

Currently implemented: Story 1.1 (profile detection/redirect) and Story 1.2 (profile creation). Everything past the home page is still a placeholder.
