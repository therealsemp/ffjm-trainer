# 2017 semi-final (sf): no usable source

This edition has been deliberately left empty: no PDF, no transcribed questions.

## Why

The two PDFs previously stored here did not belong to the same exam:

- `2017_sf_statement.pdf` was the **French** semi-final statement (18 March 2017, 31st championship).
- `2017_sf_solution-detailed.pdf` was in fact the detailed solution of the **Swiss** semi-final (25 March 2017, by Sébastien Python), a different exam.

Only two problems overlapped (Swiss 12 "Maya l'abeille" = French Q11, Swiss 18 = French Q18, the latter with lengths in m instead of cm). Several others were variants with different numbers (e.g. Swiss 14 "Echec à Matt": 24 francs vs French Q13: 21 €). The other 16 French questions therefore had no official answer or correction, and a transcription attempt (2026-09-30) could only fill them with self-computed, unsourced answers. That data was discarded rather than risk validating wrong answers.

## To re-ingest this edition

Find both official FFJM documents for the **French** 2017 semi-final, and check they match each other (same date, same problem titles), before adding them here:

- `2017_sf_statement.pdf`
- `2017_sf_solution-detailed.pdf` (or `2017_sf_solution.pdf` if only a results-only key exists, see rule 10 of `ingest/TRANSCRIPTION-GUIDE.md`)

Then delete this README.
