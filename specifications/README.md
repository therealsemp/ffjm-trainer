# Specifications

User-facing specifications for the FFJM Trainer application, organized as epics. Each epic is a subdirectory containing one user story per file.

## Epics

- **[001-account-management](001-account-management/)** — Profile management. How a user gets a local profile on first load, creates one (name + FFJM category), and later views stats, sets preferences (theme, sound feedback), or deletes the profile.
- **[002-training-mode](002-training-mode/)** — Training mode. Configuring a training session by level, answering questions one at a time with self-assessment, checking in-session stats, having progress saved continuously, resuming or restarting a session, and getting a rank (S+ to D) for each completed session.
- **[003-archives-consultation](003-archives-consultation/)** — Archive consultation. Opening a past edition (year, phase) directly from a full list, browsing its question sequence in official order (or jumping straight to any question via a summary), and toggling answers on or off.

Open an epic's directory for its story files, each with the full user story, business rules, and acceptance criteria. See [STATUS.md](STATUS.md) for what's actually implemented so far.
